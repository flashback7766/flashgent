# Skill: Execution Loop

## Objective
Turn one Decision State entry into working, tested code.

## Instructions
1. Plan — cite the Decision State entry this implements.
2. Modify files.
3. Run tests/typecheck/build/lint via terminal. Always. If nothing covers the touched logic yet, write minimal tests for it — don't skip verification because coverage is currently zero.
4. Auto-fix failures. Cap: 3 attempts per distinct error. Still failing → halt, report the exact error and your hypothesis. Do not thrash.
5. Hand off to @architect's review_build skill. Do not self-declare done.
